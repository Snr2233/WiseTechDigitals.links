## Publish for free with GitHub Pages
1. Sign in to GitHub or create a free account at https://github.com/.
2. Create a new **public** repository named `wisetech-digitals-links`.
3. Upload `index.html` to the repository's top level (not inside another folder).
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then save.
7. Wait for GitHub Pages to publish. Your page URL will usually be:
   `https://YOUR-GITHUB-USERNAME.github.io/wisetech-digitals-links/`
   Replace `YOUR-GITHUB-USERNAME` with your actual GitHub username; do not use that placeholder as a real URL.
8. Open the published page on your phone and tap **Download QR code**. The QR encodes the exact public page URL.
9. Scan the downloaded QR code using a second phone or your camera app and test every social button before printing.

## Important
- The HTML is prepared, but it is not public until you publish it.
- No permanent QR code can be generated for the final page until its public URL exists.
- The QR display uses a third-party QR image service when the published page is opened. The social buttons themselves link directly to the URLs above.
- URL syntax has been checked, but account ownership, privacy settings, and whether each platform profile is accessible to every visitor must be tested while logged out.
- If your YouTube link includes a tracking parameter you don't need, the channel URL can usually be simplified to `https://youtube.com/@wisetech.digitals`, but the supplied URL has been preserved exactly.
